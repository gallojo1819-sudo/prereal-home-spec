# PreReal — live walkthrough checklists (fill like Home)

Use one tab at a time. Click like James would. Write **where the click landed** (URL + what you see), not “seems fine.”

**How to fill**

- `y` / `n` / `?`
- For pills and buttons: `clicked X → landed on Y (filtered / not filtered)`
- Screenshot anything overlapping, truncated, or dead
- Do **not** Upload, File, Migrate, Delete, Done, Purge, Research now, or send email
- Safe: change a filter then reset, open a thread, expand a row, open Notes/History, Cancel a modal

**Tab order (Home is done)**

1. Ask
2. Needs you
3. Accountability
4. Project status
5. Records
6. Research
7. Add Data

Paste one tab back when you finish it.

---

# 1. ASK (`/ask`)

Research desk. Question → cited answer from company docs. Not tasks, not rulings, not pick-an-engine.

### A. First 10 seconds
* One sentence: what is this page for?
* Blank composer or an old thread already open?
* Can you tell **which documents** it will use (one project vs whole library)?
* Engine picker visible? Do you know what each engine is without hovering?
* Anything overlapping / truncated at laptop width?

### B. Composer
* Placeholder — does it tell you what to ask?
* Send / Stop — obvious?
* Scope chips (project / library / people) — change one. What happens?
* Attach / @ / project lock — work or dead?
* Does it warn you if the corpus is **unindexed** / empty?

### C. New answer (harmless question e.g. “What is PreReal?” — do not send email)
* Did it run? Crash? Blank?
* Sources listed? Can you **open** a source?
* Cited vs guessed — can you tell?
* Draft / copy / follow-up actions present?
* Looks like it already emailed someone? (it must not)

### D. Thread list / history
* Can you find an old thread without searching your memory?
* Click an old thread. Does the **answer come back**?
* Do **actions** come back too (copy, follow-up, sources) or is it a dead transcript?
* Rename / pin / delete sitting next to Copy? Anything you could nuke by accident?

### E. Resume (important)
* Copy a thread URL (look for `?conversation=` or similar). Open it in a new tab.
* Crash / white screen / “something went wrong”?
* Back button — does it return to the list or die?

### F. Wrong doors
* Any control that dumps you into Needs you, Records, Research, or Accountability when you meant “keep asking”?
* If you arrived from Records “Ask this silo/project,” is the **correct project locked**?

### G. 60-second job
* Question: “What did we last send Lewis on the NDA?”
* Could James ask it, see a source, and find that thread tomorrow?
* Would you use this on a phone?

# 2. NEEDS YOU (`/needs-you`)

Ruling queue. Contradictions / decisions. Not Accountability tasks and not a reprint of Home.

### A. First 10 seconds
* One sentence: what is this page for?
* Default lane? (To decide / Everything / a kind?)
* Count at the top — does it match rows on screen, or is it capped (e.g. showing 200 of 330)?
* Loading: flash of **0** then a big number?

### B. Lanes / kinds
* List every kind chip you see (contradiction, rule, precedent, etc.)
* Click each kind. Does the list **filter**, or stay on Everything?
* To decide vs Everything — actually different?

### C. First card
* Full title readable? Clickable?
* Why it needs him (two docs disagree / missing rule / …) in plain language?
* Sources on the card — can you **open the documents**?
* Actions: Decide / Defer / Ask / Dismiss — which exist?
* Decide — real ruling UI or dead click?
* Ask — Ask with this item prefilled, or a blank Ask?

### D. Document viewer
* Open a source from the first card.
* Side-by-side? New tab? Records?
* Can you see the **passage**, not just the file name?

### E. Duplicates / overlap with Home
* Same tasks as Home (Rural briefing, NDA), or different objects (contradictions)?
* Home “Rulings / contradictions” — land here **already filtered**?

### F. Dangerous / confusing
* Anything that looks like Delete on a ruling?
* Card body dead click?
* Truncation / overlap at 1280?

### G. 60-second job
* Could James pick the **one** ruling that matters this morning in under a minute?
* If no: what blocked him?

# 3. ACCOUNTABILITY (`/accountability`)

Who owes what. Home should deep-link **here**, filtered.

### A. Land / default
* Which tab is selected on arrival?
* If Everyone: how many rows? Graveyard?
* Can you get to **Mine · To do** in one click?

### B. Mine
* To do vs Done vs Everything — three real lists?
* Overdue at top?
* Click a **title** — opens / highlights, or nothing?
* Start / Done / Dismiss / Delete — which sit on the row?
* Delete: confirm modal? Undo? Instant?
* Willing to have Delete next to Done on James’s phone?

### C. Filters (Home pills need this)
* Due = Overdue — list count matches a visible number?
* Closed this week — exists? Honest?
* After Overdue, copy the URL. Does `due=overdue` (or similar) **survive refresh**?

### D. Everyone
* Default sort?
* 2007 / ancient items mixed with this week?
* Filter to a person?
* Delete on other people’s tasks?

### E. Meeting commitments
* By person vs by meeting — understandable?
* Click a commitment — where do you land?
* Sync strip — last synced when?

### F. Follow-ups / Agent drafts
* One sentence: what is this tab for?
* Send vs save draft — can you tell?
* Looks like it already emailed?

### G. Routing / role map
* Do you understand it?
* James, or staff-only chrome on a CEO page?

### H. Add a task
* Open the form (do not save). Required fields obvious?
* Default owner = you?
* Cancel after typing — warn?

### I. 60-second job
* “What is late that I own?” — without Everyone?
* Ready to receive Home `?tab=mine&due=overdue`?

# 4. PROJECT STATUS (`/goals`)

Ledger: projects, % complete, next owner.

### A. First 10 seconds
* One sentence: what is this page for?
* Blocked vs on track visible?
* Progress bars — do you believe them?

### B. Project row
* Click **project name** — expand, Records, Needs you, or dead?
* Next action — named owner + due, or vague?
* Blocked reason readable?

### C. Edit
* Type a character. Collapse without save. Warn or throw away? **Do not Save.**

### D. Deep links
* URL when a project is open — `?project=`?
* Refresh — still on that project?

### E. Overlap
* Same as Home “Project pulse”?
* Home pulse today went to Needs you — from here, where should it go?

### F. 60-second job
* “Which project is stuck and who owns the next move?” — one glance?
* Show this to your boss as the portfolio page?

# 5. RECORDS (`/workspace`)

File room. Find a document, file to a project, review unfiled.

### A. First 10 seconds
* Heading: Records / Records Hub / Workspace?
* Count: SILOS or Projects?
* Land tab?
* How many tabs? List them.

### B. Projects
* CTA: Ask this silo / Ask this project?
* Click a project card — inside, Ask, or dead?
* CREATE A SILO or New project?

### C. Find
* Search on land or only after Find?
* Search a word **inside** a doc (not filename). Hits?
* “Indexed only” helper?
* Titles readable or smashed?
* Click a result — viewer, download, new tab?

### D. Review / unfiled
* Needs a decision vs Filing decisions vs Unfiled?
* Count believable?
* Assign to project obvious? **Do not file.**
* Feels like Needs you, or a filing queue?

### E. Timeline / meetings
* Meetings / timeline tab exist?
* Home “65 meetings” went to Find — is the right tab here?

### F. Danger
* Merge / Trash / Purge — where?
* Purge forever vs Trash labeled?

### G. 60-second job
* “Find the Lewis NDA and see which project it lives in.” Without knowing the filename?

# 6. RESEARCH (`/intelligence` or `/research`)

Pick-an-engine-and-file. Not Ask. If you cannot tell them apart, write that down.

### A. First 10 seconds
* One sentence vs Ask — what is different?
* Engine list — families or a flat dump?
* **Run / Research now** enabled before engine + destination?

### B. Setup
* Destination project required before run?
* Sensitivity / silo language?
* Cost / time estimate?

### C. Chips / live triggers
* Changing a chip — start a run immediately?
* Stop / cancel if you started by accident?

### D. Output
* Result files to Records? Ask thread?
* Open output without leaving?
* Duplicate of Ask?

### E. 60-second job
* “Run one engine into the right project” without firing a live paid run?
* Run enabled with no destination = fail.

# 7. ADD DATA (`/ingest`)

Receiving dock. **Do not Upload, File, Migrate, Analyze, or connect Gmail/Fathom.**

### A. First 10 seconds
* Default tab?
* List every tab.
* One sentence: if you drop a PDF right now, where does it go?

### B. Upload — fallbacks
* Exact label of the project/sensitivity panel (screenshot).
* Says **optional / only when AI is unsure**?
* Project: whole batch, or only if AI unsure? (what does copy claim?)
* Sensitivity: floor vs optional?
* Links helper — links **skip AI**?

### C. Destination
* Before Upload, see: project, sensitivity, confidential, searchable in Ask, tasks yes/no?
* Queue empty copy?
* Legend for already-in-library / superseded / Review — visible now?

### D. Record
* Dictate vs Record — no-audio vs audio kept?
* Type one character. Draft-loss warning? **Do not file.**
* Extract action items — On/Off, or always on?

### E. Paste meeting notes
* Copy claims James’s notes + Accountability?
* If you click submit: modal or instant? **Cancel.**
* Tab look available to everyone?

### F. Monday / Import intelligence
* Monday destination: silo vs project?
* “Nothing written until Approve”?
* Migrate / Analyze disabled until ready?

### G. Language
* Find-in-page `silo` on this screen — hits in chrome?

### H. 60-second job
* “PDF into Spaceport, confidential, no tasks.” Can you set that without pressing Upload?
